Unit 6 Reaching for Space：GitHub Pages 發布說明

1. 將 ZIP 解壓縮。
2. 建立 GitHub 儲存庫，上傳解壓縮後的所有檔案及資料夾到儲存庫根目錄。index.html 應與 app.js 在同一層。
3. 在儲存庫 Settings → Pages 中，選擇 Deploy from a branch，選擇 main 分支與 / (root)，儲存。
4. 等待 GitHub Pages 建立後，使用設定頁顯示的網址開啟。

提醒：影片播放及外部連結需要網路。Trancy 請在安裝並啟用外掛的瀏覽器中，使用各段影片的 YouTube 新分頁連結；字幕依原影片提供情況而定。請保留檔案及資料夾的名稱與相對位置。
